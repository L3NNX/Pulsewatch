# Dashboard Subpage Architecture
- /dashboard: Monitors Telemetry List & Live Metrics
- /dashboard/incidents: Incident Timeline & AI Summaries
- /dashboard/alerts: Omni-Channel Alert Integrations
- /dashboard/status-pages: Public Broadsheet Configuration
- /dashboard/settings: Operator Account & API Security

- Incidents Page: Status filter tabs (All, Open, Resolved) with duration counters and failed check metrics.


- Incident Drawer: Displays HTTP response headers, SSL handshake status, and raw probe payload.


- Status Pages Manager: Configure public vanity slugs, toggle public monitor visibility, and copy live URL.


- Developer API Keys: Cryptographic token generation with masked preview and one-click copy.
